# Blueprint

Cobalt lines, cool paper, technical type, small corners, and restrained offset shadows establish a drafting character. A faint grid supports selected visual studies; clear headings and ordinary page structure carry the content. The direction remains recognizable without a moving wireframe or cursor effect.

This entry adapts Blueprint in **Tamir (Phi Vuong Tuong Tam)'s portfolio**, retaining observed values and identifying portable Atlas proposals. The source pairs Manrope interface text with JetBrains Mono accents and technical values. Atlas proposes a broader mono heading role while keeping body text and controls in sans-serif. Its original preview applies the direction to a fictional engineering studio and an architecture inspector.

## Suitability

These are Atlas assessments, not measured usability results.

| Project type | Fit | Reason and adaptation |
| --- | --- | --- |
| Engineering studio | Strong | Technical type and measured composition suit systems work and process descriptions. Distinguish diagrams, proposals, and built outcomes. |
| Developer documentation | Strong | Mono identifiers and quiet navigation support technical reference. Keep reading text in sans-serif and verify code scrolling and language coverage. |
| Systems portfolio | Strong | A drafting identity can connect problem statements, architecture, decisions, and contributions. Use real evidence in production case studies. |
| Technical product | Strong | Explicit labels and ordered detail support explanation and inspection. Blue styling alone does not establish authority or correctness. |
| Architecture explorer | Strong | Diagram nodes can be paired with a keyboard-accessible outline and readable details. Preserve an equivalent text description of relationships. |
| Agent operations | Conditional | Needs separate authority, execution, pending-command, error, connection, and recovery rules. A technical diagram is not an operational control surface. |
| Long-form publication or lifestyle brand | Conditional | Retain a comfortable reading measure and reserve mono/grid treatments for short emphasis. A softer display treatment may better fit narrative identity. |

Choose the adaptation for actual content and tasks. A visual direction does not establish agent permissions, execution, or recovery behavior. Use relevant [Agent Experience guidance](../../knowledge/agent-experience.md) when preparing an agent interface.
