# Precision

Cool neutral layers, a deliberate blue action color, restrained typography, aligned data, and compact geometry support repeated operational work. Lists and details share context; status copy separates what was requested from what is confirmed. Brief feedback keeps controls responsive and positions stable.

Precision is an **original Interface Atlas synthesis**, developed for **Tamir (Phi Vuong Tuong Tam) with Codex AI assistance**. It studies concepts from **IBM's Carbon Design System** and **GitHub's Primer**, with independently proposed tokens, component geometry, and a local reference implementation. Carbon and Primer retain their own names and authorship; neither publishes or endorses this theme. Precision is not an extracted Tamir portfolio theme.

## Suitability

These are Atlas assessments, not measured usability results.

| Project type | Fit | Reason and adaptation |
| --- | --- | --- |
| Agent workspace | Strong | Explicit lifecycle, attention, connection, and command states make agent activity inspectable. Document authority and recovery in the project contract. |
| Operations dashboard | Strong | Aligned tables, stable summaries, readable timestamps, and neutral surfaces support repeated checks. Add freshness and data provenance. |
| Administration interface | Strong | Clear grouping, visible labels, and bounded primary actions suit configuration and record work. Define validation, permissions, and confirmation separately. |
| Developer tool | Strong | Sans interface text and short monospace identifiers provide technical precision without turning every paragraph into a log. |
| Review queue | Strong | Persistent selection and an explicit path from list to evidence support comparison and deliberate decisions. Include keyboard and focus behavior. |
| Data visualization workspace | Conditional | The base supports surrounding controls and tables; a project still needs its own chart scales, legends, accessible alternatives, and update rules. |
| Portfolio or expressive campaign | Conditional | Technical presentation may fit engineering work; projects requiring imagery, expressive branding, or long narrative need deliberate adaptations. |

The theme provides a visual and interaction starting point. It does not authorize execution, decide approval policy, or define backend reliability. Load relevant [Agent Experience guidance](../../knowledge/agent-experience.md) when preparing those decisions.
