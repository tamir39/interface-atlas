# Pulse

Condensed headings, lime against ink, angled poster geometry, and generous spacing give Pulse a campaign character. Short display text carries emphasis; ordinary-width body text, stable controls, and readable schedules carry the work. Its identity is designed dark-first, with a complete light adaptation and a System appearance choice.

Pulse is an **original Interface Atlas synthesis**, developed for **Tamir (Phi Vuong Tuong Tam) with Codex AI assistance**. It studies modular CSS-token and adaptive-preference concepts from **Adam Argyle and Open Props contributors**, with additional animation-performance guidance by **Kayce Basques and Rachel Andrew**. Every palette, typography, layout, geometry, and timing value here is an Atlas proposal. Pulse is not a portfolio extraction or an official Open Props theme.

## Suitability

These are Atlas assessments, not measured usability results.

| Project type | Fit | Reason and adaptation |
| --- | --- | --- |
| Creative event | Strong | Poster emphasis and explicit program details suit a design gathering or exhibition. Keep real dates, venue, access information, and registration terms accurate. |
| Campaign site | Strong | One clear headline and a bounded accent can support a focused message. Preserve readable claims and a clear action without requiring motion to understand it. |
| Launch page | Strong | Bold short type can introduce a new offering. Product capabilities, availability, pricing, and evidence still need the project's own truth checks. |
| Community program | Strong | Session collections and a local selection model help explain a program. Add actual participation, access, privacy, and moderation behavior when needed. |
| Schedule planner | Conditional | The preview demonstrates choosing fixed sessions, reviewing overlaps, and recovering locally. Real scheduling needs timezone, travel, capacity, persistence, and service rules. |
| Long-form publication | Conditional | Retain comfortable body type and a bounded measure; reserve condensed display and angled geometry for short emphasis. |
| Agent or operations workspace | Conditional | Tone down poster prominence for repeated work and define authority, execution, pending commands, freshness, errors, and recovery independently. |

Choose the adaptation for actual tasks and content. A bright theme does not establish urgency, confidence, attendance, execution, or success. Use relevant [Agent Experience guidance](../../knowledge/agent-experience.md) when preparing an agent interface.

## Preview and validation

The **[live Pulse reference preview](https://tamir39.github.io/interface-atlas/themes/pulse/preview/)** presents an original fictional design gathering, component specimens, six sample sessions, and a local plan/review flow. The [preview notes](preview/README.md) describe its behavior; [index.html](preview/index.html) also opens offline without a build. Original HTML, CSS, JavaScript, and vector geometry include local font fallbacks and no imported Open Props implementation. Local-only body-face aliases preserve ordinary-width text when exact Barlow faces are installed; otherwise the body uses Segoe UI/sans-serif. No font file is distributed or downloaded.

The preview defaults to **System** appearance. Its hero poster retains a dark composition in both appearances; that bounded preview choice does not force the rest of a light page into dark appearance. Essential content and planning remain available independently of the optional motion study.

Read the [validation report](validation.md) for actual browser evidence and its limits. [Design.md](design.md) records separate opaque numerical color calculations. Status remains **draft**: representative checks do not establish production readiness, intended named-font rendering, complete accessibility, assistive technology behavior, real event booking, or calendar integration.
