09:00—09:45

Talk

01 / A useful beginning

Start with a better question

Turn a broad design intention into a question a team can actually explore.

Read session details

Compare three fictional project briefs. Find the assumption inside each brief, then rewrite it as an observable question. This opening talk introduces the sample day's theme: make the next decision clearer.

10:00—11:00

Workshop

02 / Shared foundations

A system with room to grow

Give recurring interface decisions a name, a role, and a useful boundary.

Read session details

Map a small fictional interface into foundations, components, and local choices. Practice explaining when a shared rule helps and when a project needs an explicit adaptation. The exercise is a design study, with no measured delivery claims.

10:30—11:15

Lab

03 / Movement with purpose

Motion that explains

Use a short transition to connect states, then test the same flow without it.

Read session details

Sketch the before and after states of a simple interaction. Choose whether movement explains anything useful, then create a static equivalent. This fictional lab treats reduced motion as part of the design rather than an afterthought.

11:15—12:00

Talk

04 / Voice & rhythm

Let the type do the work

Build a readable hierarchy before adding another decorative element.

Read session details

Read the same fictional program at three scales. Consider line length, contrast, language support, and the relationship between a display face and everyday text. The examples are illustrative, with no claim about real-event attendance or outcomes.

13:00—14:00

Workshop

05 / From thought to flow

Prototype the next decision

Make one important flow tangible, including its empty and error states.

Read session details

Choose one decision from a fictional product brief. Sketch its starting state, valid result, and a recoverable error. Keep the prototype narrow enough that someone can inspect the complete interaction without a backend.

13:30—14:15

Lab

06 / Better feedback

Make critique useful

Connect feedback to the brief and leave with a concrete next step.

Read session details

Review a fictional interface using three prompts: what is the intended task, what evidence supports the decision, and what remains uncertain? Separate an observation from a preference, then name the next design question.

        Pulse is an original Interface Atlas synthesis by Tamir / Phi Vuong Tuong Tam with Codex AI assistance. The composition, proposed colors and geometry, code, vector artwork, fictional gathering, and session fixtures were created for this preview.

        Open Props, by Adam Argyle and contributors, is a concept reference for adaptive tokens and opt-in motion. No Open Props code or tokens are imported, and Pulse is not an official Open Props theme.

        Barlow and Barlow Condensed are designed by Jeremy Tribby; upstream also credits Nguyễn Hồng Nhung for Vietnamese work. Named font files are not bundled or downloaded. Installed local faces or system fallbacks render the text.

        The web.dev animation guide, by Kayce Basques and Rachel Andrew, informs the transform/opacity approach. This study's artwork, 600ms timing, and easing are Atlas proposals; no renderer or third-party animation implementation is imported.
