# Botanical

Earthy greens, warm paper, expressive serif headings, alternating rounded corners, and selective soft shadows give content an organic character. Comfortable spacing supports stories and reading; restrained feedback keeps controls clear. The direction remains recognizable with static artwork and immediate state changes.

This entry adapts Botanical in **Tamir (Phi Vuong Tuong Tam)'s portfolio**, retaining observed values and labeling portable Atlas proposals. Manrope carries body and interface text, DM Serif Display has an expressive heading role, and JetBrains Mono supports short technical values. Atlas's original preview applies the direction to a fictional garden studio and a small reading room.

## Suitability

These are Atlas assessments, not measured usability results.

| Project type | Fit | Reason and adaptation |
| --- | --- | --- |
| Boutique site | Strong | A small set of offers or projects benefits from expressive headings and comfortable presentation. Keep actions and contact routes explicit. |
| Lifestyle brand | Strong | Earthy color and organic geometry suit narrative identity and material stories. Images, claims, and assets need their own evidence. |
| Narrative portfolio | Strong | Serif display text and calm supporting regions suit a considered account of work. Use real contribution evidence and clear project status. |
| Publication | Strong | Readable body text and bounded measures support essays and journals. Add navigation and indexing appropriate to the publication's scale. |
| Creative studio | Strong | A restrained palette can connect work, process, and a small practice identity without placing every item in a card. |
| Reading workspace | Conditional | Preserve quiet article surfaces, clear filters, stable focus, and explicit saved state. Compact controls and any persistence are project adaptations. |
| Dense operations or analytics | Conditional | Needs additional data, chart, update, and density rules. Large serif display text and decoration should have a small role around repeated tasks. |

Choose the adaptation for the project's actual content and tasks. A visual direction does not establish agent authority, execution, permission, or recovery behavior. Use relevant [Agent Experience guidance](../../knowledge/agent-experience.md) if preparing an agent interface.
