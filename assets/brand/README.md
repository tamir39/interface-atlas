# Interface Atlas brand assets

The Interface Atlas mark is an original A assembled from three folded atlas planes. The split apex suggests an atlas spine; the open center keeps the compact silhouette readable. The wordmark names the library directly.

Created for Tamir's Interface Atlas with Codex AI assistance on 2026-10-13. Codex developed the design proposal, geometry, and SVG composition for this repository in response to Tamir's brief. No stock icon, external illustration, font file, or third-party logo was copied. This authorship note does not assert trademark uniqueness or determine the repository's publishing license.

## Use

- Prefer the horizontal signature when the full library name should be visible. Use the standalone mark where the surrounding interface already names Interface Atlas.
- Keep clear space of at least one eighth of the displayed mark width around standalone marks and signatures. The built-in SVG padding is part of the asset bounds; do not crop the geometry.
- Use the standalone mark at 16 CSS px or larger; 24 px is preferable for interface navigation. Use the horizontal signature at 240 px or larger and the stacked signature at 160 px or larger.
- Scale proportionally. Do not stretch, rotate, add effects, alter the three-plane geometry, or recolor a variant without checking its contrast against the actual background.
- The mark uses three filled paths and no strokes, filters, or external references. The SVG wordmarks use live text with `'Segoe UI', Arial, sans-serif`; appearance can vary with available system fonts. No font binaries are distributed. For a production release that requires identical wordmark typography across systems, prepare an outlined export from an approved, licensed typeface.
- SVG titles and descriptions provide labels when opened directly. In HTML, give an informative `alt` to a standalone brand image; use an empty `alt` when adjacent visible text already supplies the same name.

This is Interface Atlas's library identity. It is not a required logo, palette, font, or aesthetic for Editorial or any other theme, and it should not be carried into generated project designs.
