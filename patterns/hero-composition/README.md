# Hero composition

Use this pattern when an opening section needs to explain the product or page, establish useful context and make a next route understandable. The brief and existing brand lead. A project with a resolved opening layout does not need a fresh gallery survey.

**Atlas entry:** original recipe and reference composition by Tamir (Phi Vuong Tuong Tam), with Codex AI assistance. [Sources](sources.md) credit Uilora and W3C guidance for specific reference questions. No external layout, component source, artwork, screenshots, copy or font binary is imported.

## Fit and limits

| Decision | Apply here |
| --- | --- |
| First encounter with a product or page | State a concrete promise and enough context to assess the next action. |
| Primary and secondary routes | Use real destinations or implemented actions; distinguish emphasis without hiding a useful route. |
| Long, translated or narrow content | Preserve meaning and reading order as the layout adapts. |
| An expressive theme or material style | Give supporting media a defined role and keep text/actions readable. |

The [live preview](https://tamir39.github.io/interface-atlas/patterns/hero-composition/preview/) ([local files](preview/index.html)) demonstrates an original composition, real fragment destinations and content-pressure choices. Its decorative artwork carries no service or product claim. The [preview notes](preview/README.md) and [validation record](validation.md) describe the finite specimen; it is not a complete landing page, a conversion study or nine fully tested theme combinations.
