Actual link destination

The composition decisions.

Keep the promise specific

The hero describes a planning concept. It contains no invented customer totals, testimonials or performance results.

Preserve reading order

The statement, explanation and links precede the decorative artwork in source order. Narrow screens use the same order.

Let content set the height

The longer heading can wrap, and the links can stack. Neither the main promise nor the destination needs to be clipped to fit an image.
