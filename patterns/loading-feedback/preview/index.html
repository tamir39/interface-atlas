    Keep useful context

    A first load can show an unobtrusive placeholder. A later load retains previous sample results and identifies them as previous content.

    Settled

    Different results need words

    A returned empty set replaces previous items. A failure leaves earlier items visible and offers another simulated attempt. An animation cannot establish either outcome.

    Recovery

    Reset retires the fixture

    Reset returns to the initial state. Outcome controls work only during the current pending fixture. Real retry, cancellation and late-result rules require the consuming service's contract.
