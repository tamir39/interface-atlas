# Pocket Practice — fictional consumer trial brief

Status: trial input reconstructed from the delegated brief on 2026-10-15. This is not a request to build a user product.

Pocket Practice is a responsive personal practice web app for independent learners, with a calm, approachable voice. Its English interface may display Vietnamese lesson content. Do not invent a language toggle.

Required tasks: browse and filter a small text-first lesson catalog; bookmark lessons; plan weekly practice; finish a practice with a short note; edit a goal; revisit actual completed work. Data and preferences must survive a reload in the same browser when storage works. There is no account, synchronization, backend, AI, or agent control. Address blocked, full, and malformed storage; distinguish a fresh start from unreadable data and provide useful empty lists. Edits must not disappear silently or claim persistence after a failed write.

Required appearances: Light, Dark, System. Design phone first, usable on desktop, with keyboard and reduced-motion behavior.

Content, brand assets, font files, stack, and a final product data model are not supplied. Mark markup, state ownership, storage formats, conflicts, navigation, Save versus autosave, deletion/undo, and media decisions as project proposals or open contracts. Bound any proposed export/import or recovery facility to actual needs.

Trial procedure: read the required Atlas preparation skill, catalog, two or three candidate theme READMEs, selected theme design and sources, relevant optional motion/effects and only genuinely relevant shared knowledge, plus the project template. Do not read old examples, other trials, all theme details, installed global skills, or web sources. Write only brief.md, design.md, evaluation.md and read-log.json in this staging directory. Produce a self-contained design draft around 2,000–3,000 words, including tokens, pairings, type, geometry, adaptive layout, states, flows, storage/recovery, validation boundaries and precise provenance. Do not implement or claim rendered proof or production guarantees.
