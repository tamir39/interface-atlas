# Neobrutalism composition evaluation

This evaluation applies the optional [Neobrutalism style](../../styles/neobrutalism/README.md) to bounded profiles of all nine existing Atlas themes. It separates observed browser behavior from reasoned design fit: a readable hard-shadow board does not make persistent decorative depth suitable for every theme.

The [live specimen](../../styles/neobrutalism/preview/index.html) is an original local idea board with filtering, selection and a validated brief. Its [profile manifest](../../styles/neobrutalism/preview/theme-tokens.json) retains each existing preview's palette aliases, named body/display/mono stacks and corners, with source CSS hashes and explicit role mappings. Complete themed applications, layout, assets, density and typography scales remain outside the specimen.

[Design and per-theme decisions](design.md) explain preservation and deliberate departures. [Trials](trials.md) separate browser assertions from visual inspection and record actual results. [Machine evidence](results.json) fingerprints the actual tested files and retains every matrix and interaction row. The portable [validator](../../tools/validate-neobrutalism.mjs) uses an optional installed Playwright package and Chromium; the runtime preview requires no package or network service.

On **2026-10-27**, Chromium **153.0.8010.12** passed **72 base states**, **144 measured interaction contexts** (including **72 dedicated keyboard-focus contexts**) and **11 check groups**. Minimum measured ratios were **5.036:1 for text**, **9.504:1 for control boundaries** and **9.504:1 for the sampled focus outlines**. A real forced-color punctuation defect was repaired before the corrected run. These results describe this bounded specimen and its documented exclusions.

Play has the strongest affinity because its source already combines ink boundaries with hard offset depth; its soft corners and typography remain intact. Blueprint, Botanical, Editorial, Layered and Pulse need a scoped adaptation. Gallery, Precision and Swiss conflict with persistent hard shadows as their normal surface language. These judgments remain meaningful even when the shared specimen passes numerical checks.
