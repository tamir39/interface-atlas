## Performed contexts

The base matrix is three patterns × light/dark × 320/1280 CSS-pixel widths. Additional rows inspect action, held native Space press, keyboard focus, selected state, unavailable action and reset; loading states and retained content; native hero history and long split/stacked content. All six pattern × no-JavaScript/blocked-script combinations retain readable content and disable unavailable enhancements. Native hero fragment links and browser Back/Forward operate in both fallback modes.

The button fixture actually adds three supplied items. The action's unavailable state has an explanation and moves focus to Reset. The constant-name emphasis toggle exposes its separate pressed state. Reset and reload restore their documented local state.

The loading fixture is **manually controlled**. Busy state belongs to the result region; the status is outside it. Success supplies three original results. Starting again retains them; failure retains them with a visible retry message; an explicit empty result replaces them. Reset retires the pending fixture, and a later programmatically dispatched outcome event cannot populate the reset state. This checks local fixture guards, not a server or remote cancellation guarantee.

The hero uses one page h1 and an example h2. Real links target readable sections, preserve browser history and work before JavaScript. A native Space toggle selects longer original content; split and stacked layouts retain that content and have no page overflow.
