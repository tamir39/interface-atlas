# Next Up composition evaluation

**Next Up** is an original Atlas reference task: inspect four fictional frontend tasks, complete or reopen them, filter by state and add a small task with an explicit priority. It applies the [Flat Design grammar](../../styles/flat-design/style.md) through opaque color planes, visible field boundaries, native checkboxes, named actions and consistent grouping. Flat does not mean square, empty or minimally functional.

The [live preview](https://tamir39.github.io/interface-atlas/styles/flat-design/preview/), [local preview](../../styles/flat-design/preview/index.html), [design contract and nine fit decisions](design.md), [trials](trials.md), [machine-readable evidence](results.json) and [optional browser validator](../../tools/validate-flat-design.mjs) separate implementation behavior, source fit and finite evidence. A shared profile pass does not validate a complete theme application.

Four tasks and their original text exist in the initial HTML. JavaScript enables completion, All/Open/Done filtering and a title/priority form. Invalid titles receive a described error and focus; a task hidden by the chosen filter is explained and can be recovered through Show all. State, drafts and preferences last only while the page is open. Reload restores the four originals; no account, backend, durable save or export exists.

The generated adapter retains 15 source variables, nine source fingerprints and 18 light/dark identities. Actual authored panels and ordinary controls retain the selected card/control radii, including Botanical's alternating corners. Native checkbox/popup internals remain browser-controlled. Named font stacks are declared without shipping font binaries. Removing source depth changes identity even when radii and color survive.

Entry authorship and research credits belong in [sources.md](../../styles/flat-design/sources.md). The specimen, fictional task text and validator are original Atlas work; no outside interface, code, art or font file is imported. Status remains **draft**.
