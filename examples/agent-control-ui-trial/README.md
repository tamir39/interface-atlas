# Harbor Desk — implemented local UI trial

An original, bounded agent-operations simulation, `0.1.0`, prepared 2026-11-05. **No real service, agent, delivery or external publishing exists.** This trial evaluates a concrete interface built from the historical fictional Harbor Desk contract; it does not validate that contract as a production service.

Open the [Harbor Desk Pages preview](https://tamir39.github.io/interface-atlas/examples/agent-control-ui-trial/preview/), or [preview/index.html](preview/index.html) locally in a modern browser. It has no build, dependency, remote request, font download or image download. A local static server can supply a consistent origin for reload checks; file-URL storage behavior varies by browser. The Pages build publishes only the three preview files; supporting documents link to the repository. The original local trial and its source identities remain recorded in the evaluation.

Choose one of three requests, inspect its version and sources, then dispatch its fictional publish decision. Open **Local fixture controls** to advance acceptance, confirmed effect, reply loss, replacement proposal, permission loss, correction applicability, best-effort cancellation or a later effect. A lookup event stages evidence; **Check status** deliberately observes it. Each control explains the boundary it demonstrates. Nothing advances on a timer.

- [Interaction and design handoff](handoff.md): resolved local behavior, gates, focus and retention boundary.
- [Source identities and credits](credits.md): selected draft guidance, Precision, installed skills and retained notices.
- [Implementation and read report](implementation-report.md): exact reading, implemented scope and limits.
- [Independent evaluation](evaluation/report.md): root-owned review and browser evidence, separate from implementation assertions.

The appearance control offers light, dark and system. Editable unsent text is memory-only; deliberately saved/submitted fictional snapshots are retained locally. A visible local-fixture reset clears this simulation’s record, with no claim of cancellation, recall or rollback.
