# Request list design

The existing filter toolbar contains labelled Attention and Status native selects. Attention has all/needed; Status has all/open/done. Clear filters is a type=button control after the selects, labeled Clear filters, restoring both to all and rendering the full list. Activation preserves focus on that button; use native keyboard behavior. No design-system change is needed. The page uses system-ui, a white surface, #17202a text and a visible focus outline.
