# Neumorphism composition evaluation

This evaluation applies optional [Neumorphism](../../styles/neumorphism/README.md) to bounded profiles of all nine existing Atlas themes. It separates measured browser behavior from authored design fit: a readable soft surface does not make that material an appropriate default for a theme.

The original [Quiet page specimen](../../styles/neumorphism/preview/index.html) is a reading-preset workbench. Choose a draft measure, name, text size and line spacing, then Apply to change an actual reading sample. A dirty or invalid draft leaves the applied sample intact. Reset restores both draft and sample. No preset is stored and no browser or operating-system preference is changed.

The generated [profile manifest](../../styles/neumorphism/preview/theme-tokens.json) preserves 15 variables from each actual theme preview, including named font roles, exact light/dark values, mappings and source CSS hashes. The selected material scope retains each host's panel corners. Its plane, host and opaque face use the same Surface RGB; shallow opposing shadows suggest raised or recessed depth around a 12px rim. The face derives each corner as `max(0px, host corner - 12px)` and shields all readable content from inset shading. Ordinary fields/actions retain source control corners and their own verified roles. Complete theme applications, assets, density and typography scales are outside this example.

[Design and per-theme decisions](design.md) explain preserved roles, material departures and the contrast method. [Trials](trials.md) record the actual browser run and bounded visual observations. [Machine evidence](results.json) retains every recorded context row, source/runtime identity and raw-report fingerprint. The optional installed-Playwright [validator](../../tools/validate-neumorphism.mjs) reproduces the checks; the runtime needs no package, remote asset or network service.

On **2026-10-27**, headless Chromium **153.0.8010.12** with Node **v24.14.1** passed **72 base states**, **198 measured interaction contexts**, including **72 dedicated keyboard-focus contexts**, and **11 check groups**. Minimum measured ratios were **5.036:1 text**, **3.615:1 field borders**, **3.162:1 button boundaries**, **9.504:1 selected outlines** and **9.504:1 keyboard focus**. A visible decorative heading mark failed the first forced-color contrast trial and was corrected to CanvasText before the recorded final run.

Botanical and Editorial permit bounded adaptations of selective soft depth, while their shape and reading hierarchy still govern. Play's tactile character gives limited affinity, but shallow soft depth replaces its authored hard offsets. Pulse needs a small intentional departure from flat task surfaces. Blueprint, Gallery, Precision and Swiss conflict with Neumorphism as their normal material language. Layered explicitly rejects inset bevels simulating physical controls. The nine browser profiles therefore do not establish nine unchanged compatible themes.
