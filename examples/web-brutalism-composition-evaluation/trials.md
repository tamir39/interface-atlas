# Open Index trials

These trials concern one content-first Web Brutalism document, not the entire style family or complete source themes. [Design](design.md) records task semantics, explicit geometry overrides and nine independent fit decisions. [Results](results.json) preserves the final compact evidence and hashes.

## Source and prototype decisions

The adapter retains 15 source variables and nine original theme stylesheet fingerprints. Actual controls and sections deliberately use 0px corners instead of the source geometry values. Plain sections, 1px rules, native checkboxes and underlined fragment links support six original static notes. Gallery's image-led identity, Play's hard depth, Botanical's organic corners and the other source constraints were assessed afresh for this task. Surface restraint does not make every theme interchangeable or validate more expressive brutalist work.

## Diagnostic findings

1. The first diagnostic reached four base states. The brand anchor's removed underline violated the chosen link rule; the preview restored its underline. A separate validator mistake assumed an unquoted YAML accessibility snapshot. Chromium serializes the native checkbox name inside a quoted YAML scalar; the parser was corrected to read the actual name. No accessible label was changed to satisfy the parser.
2. The next run passed all 72 base and 180 interaction contexts, plus native navigation, title bounds, filtering and the actual download. It then found a real reduced-motion bug: the motion-on selectors for text/search inputs were more specific than the later reduced-motion override. The inputs retained a 100ms transition while other controls were immediate. Matching input-type specificity repaired both reduced-motion and forced-color overrides.
3. A complete diagnostic then passed all 17 functional check groups, base/interaction contexts and forced/no-JavaScript fallbacks. Forced-color screenshot framing was refined to capture bounded 320×900px native-checkbox, title and primary-action views. This was an evidence-framing change, not a preview behavior change.
4. The final frozen run on **2026-10-27**, Node **v24.14.1**, Chromium **153.0.8010.12**, passed **72 base states**, **180 measured interactions** including **90 keyboard-focus contexts**, and **17 check groups**. Preview and validator hashes were checked again before completion. The validator source hash is recorded in results.json; no file was edited during that run.

The final 252 base/interaction contexts contain 38,574 visible text samples. Minimum ordinary-text contrast was **5.627:1**; minimum large-text contrast was **5.627:1**. Minimum necessary field/action boundary contrast was **3.398:1** and minimum measured keyboard-outline contrast **10.651:1**. Controls/index links/summaries and native checkbox label areas were at least **95.61px wide × 44px high**. These numbers describe finite measured contexts, not every possible pairing or all native browser pixels.

## Task evidence

The final run verified all six articles are visible in every measured state. Same-viewport native checkbox accessible names stayed stable after selection. Space toggled a native checkbox; skip navigation moved to the real main region. Fragment links changed the actual URL, and real browser Back/Forward recovered previous fragment destinations with JavaScript enabled, disabled and initialization aborted. Filters hid index rows only and kept the fragment's article readable.

Three notes selected in reverse click order survived filtering and preference changes. The status correctly reported **3 selected / 2 hidden selected**. The file exported the original document order: document-order, reading-type, motion-choice. Clear restored all six index rows and preserved the native fragment. Required/trimmed short and whitespace failures focused the described title error; a programmatic 49-character value failed and an unbroken 48-character value exported and reflowed at 320px.

The actual **2,222-byte UTF-8** file `open-index-reading-plan.txt` decoded successfully. It contained the trimmed **Café <b>reading</b> plan** title as literal text, all selected original topics/prose and canonical public note URLs. It excluded unselected titles/prose and private filesystem paths. The inspected file SHA-256 is `9af5a3b2845e5d797dfe770f26e360eba84e25c64ba56ec9098e53466d74662f`. Reload reset plan selection, title, filter and preferences; native URL context remained browser-owned.

## Rendered and fallback inspection

Bounded final 320×900px forced-color screenshots were opened and inspected at original resolution. The title value and correction hint remain readable within its visible black outline. The native checked checkbox has a distinct check and focus boundary beside its stable label. The primary action's words remain readable during pointer-active state. Its underline conveys activation without movement. Native checkbox paint uses browser system selection colors; it is not forced into an authored glyph.

The computed checks compare actual document/heading punctuation to CanvasText, the body to Canvas, ordinary document links to LinkText, native fields/actions to ButtonText/ButtonFace and actual focus to CanvasText. The skip action uses ButtonText/ButtonFace as an explicit exception to ordinary document link roles. Unused root Focus values are not rendered-focus evidence. Native popup, checkbox glyph internals, placeholder text and antialiasing remain outside contrast arithmetic.

System appearance followed live media changes. Reduced motion and forced colors overrode explicit motion-on to zero duration. JavaScript-disabled and intentionally aborted initialization preserved exact original prose, native links/history/disclosures and readable disabled-tool explanations. There were no ordinary runtime errors, failed resources or external requests; the aborted script was recorded separately as an intentional failure.

## Evidence storage and limits

The final raw report is **59,373,061 bytes** and stays with the temporary browser run. Its SHA-256 is `fd5e5c77e2f110892e462d67de0e7a11bf8420868961720f52f432b21bda3ad2`. The **133,080-byte** committed projection retains every matrix/interaction row, 18 computed identities, nine source fingerprints, five runtime hashes, validator/raw hashes, actual accessible names, history states and download evidence. Temporary PNGs and downloads are not added to the repository.

This is Chromium-only evidence. It does not establish screen-reader behavior, other engines, physical devices, native zoom/text enlargement, intended font-binary rendering, full accessibility conformance, a user study, backend behavior, performance or complete theme applications. Status remains draft.
