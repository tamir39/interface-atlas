## Inputs, integrity and limitations

The [protocol](protocol.md) was written before dispatch. The base repository was clean `dev` at `83e43077ab5bc5478a6a1d22f1cc4d3ab81cc172`; the evaluated A–D changes were **uncommitted**. [Snapshot identities](snapshot.json) identify the actual 63 eligible files. [Frozen source text](source-snapshot.json) preserves their bytes as UTF-8 strings; decoding each string recovers the recorded hash. A base commit alone does not identify the new guidance. Original brief bytes were preserved from `examples/p0-evaluation`; wrappers supersede only their historical workflow/revision wording, not product requirements.

The [read audit](read-audit.json) replays every successful content selector and metadata identity against frozen inputs and first drafts. No source or returned-content hash mismatch was found. All agents reported no displayed source truncation. Logged returned bytes establish emitted content, not independently measured comprehension or a host's complete automatic discovery behavior.

One bilingual-generation read of `references/licenses/jakub-krehel-MIT.txt` was rejected because full notice files were omitted from the frozen reader allowlist. It was not bypassed. Root clarified the procedural distinction between unavailable text and unknown rights; the full notice exists in Atlas, its recorded MIT terms remain, and distribution requirements are preserved. This is a harness limitation, **not** evidence that the workflow naturally avoids every notice read. A helper amendment added only the named harness-preflight run; trial source/selector semantics stayed unchanged. Machinery versions and procedural interventions are recorded in [evidence.json](evidence.json). The probe also reported initial shell/cwd failures before any helper input was returned.

The probe is a directed synthetic capability check created after studying A, not a held-out generalization test. Its invented provider is not a real creator whose rights were verified. It performed no contrast calculation; it correctly refrained from adopting an unsupported claim. Full same-task rendered theme comparisons, specimen interactions, motion performance, browser/storage/service behavior, assistive technology and observations of users were not tested. Three familiar briefs, different contexts and selected themes do not isolate a causal effect of A–D. No service, translation pack, licensed media or font binary was supplied.
