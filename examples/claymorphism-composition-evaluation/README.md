# Claymorphism composition evaluation

This evaluation applies optional [Claymorphism](../../styles/claymorphism/README.md) to bounded profiles of all nine existing Atlas themes. It separates observed browser behavior from source-based design fit: a readable inflated surface does not make that material an appropriate default for every theme.

The [live specimen](../../styles/claymorphism/preview/index.html) is an original creative-practice picker with a validated browser-local session review. Its [profile manifest](../../styles/claymorphism/preview/theme-tokens.json) preserves 15 variables from each actual theme preview, with named font stacks, exact light/dark values, mappings and source hashes. Selected clay shells deliberately override source panel shapes to 28px outside and 16px inside a 12px material frame; ordinary fields and working panels keep the host geometry. Complete themed applications, assets, density and typography scales remain outside this example.

[Design and per-theme decisions](design.md) explain preserved roles, shape departures and the contrast method. [Trials](trials.md) record actual browser checks, the forced-color repair and bounded visual inspection. [Machine evidence](results.json) retains every state row and the actual source/runtime identities. The optional installed-Playwright [validator](../../tools/validate-claymorphism.mjs) reproduces the matrix; the runtime preview needs no package, remote asset or network service.

On **2026-10-27**, headless Chromium **153.0.8010.12** with Node **v24.19.0** passed **72 base states**, **180 interaction contexts**, including **72 dedicated keyboard-focus contexts**, and **11 check groups**. Minimum measured ratios were **5.036:1 text**, **3.615:1 field boundaries**, **3.162:1 button boundaries** and **5.321:1 selected/focus outlines**. Opaque inner-content containment is checked independently because inset shadows are not RGB backgrounds. A real forced-color rendering defect found by visual inspection was repaired before the recorded corrected run.

Play has the strongest affinity, but clay explicitly replaces its hard offset depth and 30px panel shape. Botanical, Editorial and Pulse require scoped adaptations. Blueprint, Gallery, Precision and Swiss conflict with clay as their normal surface language. Layered's source explicitly rejects inset-beveled physical controls, so its ordinary workspace is also a conflict; a creative illustration treatment is a substantial bounded departure. These judgments remain separate from numerical browser passes.
