# Framework adapters

Theme rules are framework independent. This pilot contains no framework adapter.

Add an adapter when a project needs concrete mappings such as semantic tokens to CSS variables, font loading, accessible component behavior, or reduced-motion integration in a specific stack.

Keep framework-specific code and dependency decisions here rather than making them mandatory theme requirements. Record the official documentation and package versions used. A project may use Editorial without using the portfolio's original Next.js, Tailwind, or animation packages.
