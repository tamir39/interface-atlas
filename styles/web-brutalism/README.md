# Web Brutalism

A direct document, visible structure and recognizable browser interactions put reading and navigation first. This **composition** entry explores one content-first interpretation of a varied label. It can accompany a theme when its structural changes suit the project.

**Atlas entry:** original interpretation by Tamir (Phi Vuong Tuong Tam), with Codex AI assistance. **David Bryant Copeland** is credited for his authored *Guidelines for Brutalist Web Design* viewpoint; **Brutalist Websites** is a broader directory reference. Neither source establishes a sole creator of the family. [Sources and credits](sources.md) separate their work, terms and dates from Atlas's recipe.

## Fit and limits

| Candidate use | Atlas recommendation |
| --- | --- |
| Public documentation or reading index | Consider this content-first recipe where direct navigation and complete readable articles serve the task. |
| Creative publication | Consider it when the publication's identity supports an exposed document structure. Expressive experimental variants need a fresh assessment. |
| Selected product surfaces | Scope it to an index, reference area or publication; assess the actual forms and workflows separately. |
| Dense application or strong material identity | Flattening depth and corners changes that identity. Record an explicit adaptation and verify the working surface. |

These are conditional Atlas judgments. The label does not guarantee accessibility, speed or usability. Web brutalism also covers expressive experiments; it is broader than this specimen. [Neobrutalism](../neobrutalism/README.md) uses a different outlined, hard-shadow form recipe. Minimal and flat interfaces can share visual features without sharing this approach.
