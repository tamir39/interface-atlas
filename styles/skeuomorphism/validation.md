# Skeuomorphism validation

The [Fieldbook composition evaluation](../../examples/skeuomorphism-composition-evaluation/README.md) tested a bounded notebook task across nine actual Atlas theme profiles on **2026-10-27**. It preserves 15 source-profile variables, source outer cover/index corners and ordinary-control projection. The paper artifact explicitly uses **2px corners**. Editorial's projected ordinary controls are the source preview's 12px text-entry adaptation, distinct from original capsule buttons. Complete themed applications remain outside scope.

Headless Chromium **153.0.8010.12**, Node **v24.14.1**, passed **72 base states**, **198 measured interaction contexts**, including **90 keyboard-focus contexts**, and **13 check groups**. The matrix spans nine profiles × light/dark × 320/1280px × motion off/on. All 18 computed identities and nine source CSS fingerprints matched. [Machine evidence](../../examples/skeuomorphism-composition-evaluation/results.json) preserves every context row/schema, actual accessible names, task/download outcomes, runtime/validator hashes and the temporary raw-report fingerprint.

Minimum ratios were **5.627:1 visible text**, **3.615:1 necessary fields**, **3.615:1 button boundaries**, **10.282:1 selected outlines** and **10.282:1 keyboard focus**. Normal text requires 4.5:1; large text 3:1. Necessary field borders against fill and parent, button border/fill against parent, selected and keyboard outlines require 3:1. Focus is 3px with a 3px gap and checked for ancestor clipping. All measured enabled controls met Atlas's 44px comfort goal.

Rules, binding, page edges and shadows are not arithmetic RGB backgrounds. Separate checks verify opaque Raised faces containing every readable descendant, empty decorative layers below those faces, binding outside the reading face, source cover/control geometry and the explicit paper override. Bounded final screenshots supplement these structural checks. The [method and exclusions](../../examples/skeuomorphism-composition-evaluation/design.md#browser-method) keep this separate from complete pixel or accessibility certification.

Native skip navigation, Space note selection and stable actual accessible names passed. The form rejects required/trimmed failures and programmatic out-of-bound title/body values, associates errors and focuses the first invalid field. Apply changes actual applied reading/index text; literal markup stays text. Per-note raw drafts survive switches and preference changes. Revert restores only the current draft to its last applied snapshot. Search uses applied title/body/tags, retains hidden opened context/draft and announces recovery; Clear restores index order. Valid 48-character title/240-character body values reflow at 320px. Reload resets page memory.

A real **171-byte UTF-8 download** named **fieldbook-small-route.txt** contained the applied title, accented café body and tags while excluding a dirty draft. Its filename, decoded content and SHA-256 were asserted. No durable save, storage or backend exists.

Live System appearance, reduced-motion override, forced colors, JavaScript disabled and aborted initialization passed. Forced-color rendered QA found theme field/muted colors surviving an inherited forced-color rule; body-scoped system roles and explicit Canvas fields corrected it. Final Canvas/CanvasText content, ButtonFace/ButtonText actions, heading punctuation, selected text and actual CanvasText focus are readable; decorative material/motion is removed. [Trials](../../examples/skeuomorphism-composition-evaluation/trials.md) distinguish this preview repair from validator-only selector and unused-token assertion corrections. Ordinary runtime/resource failures and external requests were absent.

Source-based fit remains independent of browser behavior. Print-informed hierarchy or an opaque material-role system does not imply literal paper chrome. Read the [nine fit decisions](../../examples/skeuomorphism-composition-evaluation/design.md#fit-decisions).

Limits: Chromium only; no screen reader, physical device, other engine, native zoom/text enlargement, intended font binaries, meaningful imagery, complete themed app, backend, performance study or user study. Computed contrast excludes hidden/placeholder text, native popup/validation UI, glyph internals, SVG paths and antialiasing; visible decorative HTML punctuation is included. This is finite implementation evidence, not universal theme compatibility or full accessibility conformance.
