# Skeuomorphism

Familiar physical artifacts give a digital task a recognizable shape: a notebook has indexed sections, layered page edges and a binding. The Atlas recipe combines that metaphor with a restrained material treatment while preserving the host theme's palette, typography and ordinary controls. A flat folder icon alone does not establish the full physical-material style.

**Atlas entry:** original interpretation by Tamir (Phi Vuong Tuong Tam), with Codex AI assistance. David Canfield Smith, Charles Irby, Ralph Kimball and Bill Verplank are credited for their Star office-metaphor account; Apple for Aqua and iBooks. No universal inventor is assigned. [Sources and credits](sources.md) separate authorship, historical evidence and reuse terms. No external artwork, screenshot, article prose or component code is imported.

## Fit and limits

| Candidate use | Atlas recommendation |
| --- | --- |
| Personal notes, collections or reading tools | Use one coherent artifact where its organization helps explain the task. |
| Selected product surfaces | Keep the metaphor bounded; use explicit labels and native actions. |
| Dense operational workflows | Prefer calm working regions. Extra bindings, grain and page stacks can compete with data. |
| Dark appearance | Keep the host's dark roles; paper does not require white or brown. |
| Flat or restrained theme | Declare physical depth and artifact geometry as departures; profile rendering alone proves no general compatibility. |

These fit judgments concern the notebook reference; other metaphors need their own assessment. A durable-looking notebook can imply saving: **Fieldbook keeps changes only in this open page's memory**. Reloading loses them; downloading creates an actual file containing the applied note.
