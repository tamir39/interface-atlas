# Neobrutalism

Opaque color blocks, assertive outlines and hard offset shadows give selected surfaces a direct, graphic presence. This form language can accompany a theme; it does not replace the project's typography, palette, layout or interaction model.

**Atlas entry:** original interpretation by Tamir (Phi Vuong Tuong Tam), with Codex AI assistance. **Samuel Breznjak (ekmas)** is credited for the contemporary Neobrutalism components implementation and explanation referenced during research. This is not a claim that he invented the wider style. [Sources and credits](sources.md) distinguish authorship, adjacent web brutalism and reuse terms.

## Fit and limits

| Candidate use | Atlas recommendation |
| --- | --- |
| Expressive brand, creative portfolio or consumer app | Play has strong affinity; other themes need scoped adaptation that supports their identity and content. |
| Selected product surfaces | Apply to a small set of actions, selectable cards or supporting panels with clear hierarchy. |
| Dense forms, tables, editors or sustained reading | Keep working regions calm; repeated heavy borders and shadows can compete with information. |
| Dark or restrained theme | Preserve its palette and geometry. Use a readable theme Ink edge; bright candy colors are optional. |
| Intentionally disorienting or inaccessible interaction | Outside this recipe. Visual confidence does not excuse unclear controls or unreadable content. |

These are Atlas suitability judgments, not measured user outcomes. A passing specimen profile does not establish that the style suits every surface in a theme.
