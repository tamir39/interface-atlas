## Critical reading

Malewicz describes same-material extrusion and opposing shadows, then explicitly criticizes the weak contrast of a pressed state made only by reversing depth. He suggests additional visual cues. His earlier reassurance about sufficiently contrasted icons is presented as an assumption awaiting testing; it is not accessibility evidence for Atlas or permission to omit necessary boundaries.

Atlas consequently requires explicit control edges, independent selected marks/text, programmatic state and actual contrast checks. Its opaque face shields foreground from inset shading. This is an original adaptation that deliberately prioritizes a readable working surface over a perfectly seamless material illusion. Numerical shadow recipes or a visually appealing reference cannot establish conformance or measured user benefit.

## Accessibility and platform references

The following pages were inspected **2026-10-27**.

| Source | Verified fact and limited role |
| --- | --- |
| [Contrast (Minimum), SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) | **4.5:1** for ordinary text and **3:1** for qualifying large text, with defined exceptions. Check actual foreground/background pairs. |
| [Non-text Contrast, SC 1.4.11](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) | Generally **3:1** for necessary visual information identifying controls, states and meaningful graphics against adjacent colors, with defined exceptions. | [Target Size (Minimum), SC 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) | **24 by 24 CSS pixels**, with exceptions and spacing conditions. Atlas's 44px control height is a separate choice and does not alone assess a target. |
| [Button pattern — ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/patterns/button/) | Toggle-style buttons expose `aria-pressed` and keep a stable accessible label. Native button keyboard behavior and context-appropriate focus remain part of the interaction contract. The guide is informative rather than an accessibility certificate. |
| [Animation from Interactions, SC 2.3.3](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html) · [Technique C39](https://www.w3.org/WAI/WCAG22/Techniques/css/C39) | The **Level AAA** criterion concerns disabling nonessential interaction motion; C39 describes `prefers-reduced-motion` as one sufficient technique. **W3C CSS Working Group**, including the editors and contributors named in [CSS Color Adjustment Module Level 1](https://www.w3.org/TR/css-color-adjust-1/), is credited for the forced-color and color-scheme model. Its [forced-color section](https://www.w3.org/TR/css-color-adjust-1/#forced) explains user-agent palette adjustment. Atlas supplies a static fallback with system surfaces, paired text colors, boundaries and explicit state marks after decorative shadows disappear.

W3C material has its own linked copyright and reuse notices. No standards prose, diagrams or sample code are imported. Understanding pages and techniques explain requirements and examples; they do not certify this style.
