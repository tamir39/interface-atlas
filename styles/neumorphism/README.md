# Neumorphism

Shallow raised and recessed forms seem shaped from one opaque surface. Paired light and dark shadows suggest depth; readable content, identifiable controls and explicit state cues carry the interface. Often called **Soft UI**, this form recipe accompanies a theme while retaining its typography, palette and geometry.

**Atlas entry:** original interpretation by Tamir (Phi Vuong Tuong Tam), with Codex AI assistance. **Jason Kelley** is credited for the naming proposal, **Michał Malewicz** for explanation and popularization, and **Oleksandr Plyuto** for the influential banking concept discussed by Malewicz. These are distinct contributions, not a sole-inventor claim. [Sources and credits](sources.md) record dates, evidence and unresolved reuse terms. No external artwork or component code is imported.

## Fit and limits

| Candidate use | Atlas recommendation |
| --- | --- |
| Reading or personal tools | Try a few preset choices or supporting surfaces beside a calm working area. |
| Selected product surfaces | Keep plane, shell and readable face the same opaque fill; supply real boundaries and persistent state marks. |
| Dense forms, tables or extended text | Keep working regions quiet. Repeated soft controls can obscure hierarchy. |
| Dark appearance | Resolve restrained dark shading separately; bright rims are optional. |
| Flat or restrained theme | Declare the departure. Swiss, Precision, Gallery and Layered have explicit conflicts with this treatment on ordinary surfaces. |

These are Atlas suitability judgments, not measured user outcomes. Reversing shadows alone provides a weak pressed or selected cue. A passing specimen profile does not establish theme compatibility or accessibility.
