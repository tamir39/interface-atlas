# Claymorphism validation

The [composition evaluation](../../examples/claymorphism-composition-evaluation/README.md) tested this optional style over bounded profiles of all nine existing Atlas themes on **2026-10-27**. Each profile retains 15 actual source variables and named font roles. Selected clay shells explicitly override source geometry to 28px outside, a 12px material frame and 16px inside; ordinary native fields and working/settings/studio panels retain source geometry. Complete themed apps remain outside this evaluation.

Headless Chromium **153.0.8010.12** with Node **v24.19.0** passed **72 base states**, **180 interaction contexts**, including **72 dedicated keyboard-focus contexts**, and **11 check groups**. The matrix covers nine actual profiles, light/dark, 320/1280px and motion off/on. All 18 computed identity sets and all nine source CSS hashes matched. [Machine evidence](../../examples/claymorphism-composition-evaluation/results.json) retains every context row, source/runtime identity and raw-report hash.

Minimum measured ratios were **5.036:1 text**, **3.615:1 field borders**, **3.162:1 button boundaries** and **5.321:1 selected/focus outlines**. Text uses 4.5:1 normally and 3:1 when large. Fields require real border contrast against fill and parent; button boundaries and independent focus/selection outlines need 3:1 against the adjacent parent. All measured controls met the 44px Atlas comfort goal. [Method and exclusions](../../examples/claymorphism-composition-evaluation/design.md#browser-method) describe the actual computed sRGB checks.

Inset shadows are not RGB backgrounds. Separate structural checks require a direct opaque, shadow-free inner child containing every readable clay descendant, with shading reserved around the material frame. Bounded screenshots were inspected for shading placement and readability. Selected text/`aria-pressed`, associated title/minutes errors, native keyboard selection, skip navigation, local review, preference continuity, stale-review invalidation and reset recovery passed. Live System appearance, reduced-motion override, narrow forced colors, no JavaScript and aborted initialization passed. Ordinary runtime/resource failures and external requests were absent.

Manual inspection found a real forced-color defect after the first numerical pass: automatic text backplates obscured selected and primary-action text on Highlight fills. Forced selected content now uses Canvas/CanvasText and the primary action ButtonFace/ButtonText. The corrected run and its screenshots preserve visible words, independent selection/focus and ordinary boundaries. The [trial record](../../examples/claymorphism-composition-evaluation/trials.md#rendering-defect-repair-and-visual-inspection) records this repair and inspection scope; temporary PNGs are not shipped.

Browser behavior does not decide fit. Play has the strongest affinity but still changes its source hard depth and panel corners. Botanical, Editorial and Pulse need bounded adaptations. Blueprint, Gallery, Precision and Swiss conflict with inflated clay as their normal surface language; Layered's explicit no-inset-beveled-controls rule also makes it a conflict for ordinary work, with only a substantial bounded creative departure. [Per-theme decisions](../../examples/claymorphism-composition-evaluation/design.md#fit-decisions) explain the actual source constraints.

Limits: Chromium only; no screen reader, physical device, other engine, native zoom/text enlargement, intended font binaries, meaningful imagery, backend or performance benchmark. Hidden/placeholder text, native popup/validation UI, glyph internals, SVG paths and antialiasing are outside the computed contrast scope. Visible decorative HTML text is included. This is bounded implementation evidence, not accessibility conformance or complete theme compatibility.
