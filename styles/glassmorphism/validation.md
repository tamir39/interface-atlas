# Glassmorphism validation

The [composition evaluation](../../examples/style-composition-evaluation/README.md) tested the optional style over bounded token profiles of all nine existing themes on **2026-10-27**. These profiles reuse actual palette aliases, named font stacks and corners from the existing previews; they do not reproduce or revalidate the full themed apps.

Headless Chromium **153.0.8010.12** with Node **v24.14.1** passed **216 matrix states**, **72 selected/error states**, **18 settings-select focus samples** and **13 check groups**. The matrix covers light/dark appearance, calm/bright/busy CSS backdrops, automatic/opaque transparency and 320/1280px widths. Actual computed profile values matched the generated manifest and all nine source CSS hashes. [Machine evidence](../../examples/style-composition-evaluation/results.json) records source identities, rows, exclusions and the raw report hash.

Visible HTML text was checked using actual computed alpha fills over conservative sRGB backdrop bounds, rather than relying only on opaque source tokens. The lowest conservative text ratio was **5.627:1**, field boundary ratio **3.615:1**, and the measured settings-select focus ring **5.986:1** against its adjacent opaque surface. All essential data/form regions remained opaque. Normal text uses a 4.5:1 threshold, large text 3:1, field boundaries and the sampled focus ring 3:1. The [evaluation design](../../examples/style-composition-evaluation/design.md#browser-method) states compositing assumptions and exclusions.

Keyboard selection, skip navigation, labeled fields, required/minlength validity flags, associated inline error feedback, local review and reset recovery passed. Live system appearance, reduced motion, supported CDP reduced-transparency emulation and forced colors passed. No-JavaScript and aborted-script trials retained readable static content with disabled runtime controls. A removed-`@supports` branch tested the CSS base fallback; it does not emulate a genuinely unsupported browser engine. Ordinary runtime/resource errors and external requests were absent.

The first run exposed a real reduced-transparency cascade bug. OS material and forced-color overrides were corrected, then the suite was rerun. The [trial record](../../examples/style-composition-evaluation/trials.md#repairs-and-inspection) preserves the failure, repair and visual-inspection scope. Screenshots remain temporary and are not shipped assets.

Passing this specimen does not settle design fit. Blueprint, Botanical, Editorial, Layered and Pulse need a scoped adaptation; Gallery, Play, Precision and Swiss conflict with glass as their normal surface treatment. [Per-theme decisions](../../examples/style-composition-evaluation/design.md#fit-decisions) identify the preserved roles and reasons. Opaque fallback remains a valid outcome.

Limits: Chromium only; no screen reader, physical device, other engine, native zoom/text enlargement, real backend or performance benchmark. Named font binaries, imagery fidelity, disabled/placeholder text, native popup/validation UI, decorative/SVG content and antialiasing are outside the measured contrast scope. This is bounded implementation evidence, not accessibility conformance or universal theme compatibility.
