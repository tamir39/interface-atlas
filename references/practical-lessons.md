# Practical lessons from Atlas exercises

Load only an example relevant to a current decision. Source advice is attributed guidance; Atlas experience requires an identified exercise and evidence. Preserve the original draft, finding and correction. Historical schema, service policy, theme and numerical values are not defaults for another project.

Use a proportionate lesson card: applicable condition; date and artifact revision/location; evidence level; trigger and consequence; counterevidence and interpretation; bounded correction; verification performed; remaining checks; relevant creators, source pins and terms.

The following are **document-trial findings dated 2026-10-17**, not observed failures in implemented products. Corrections were reviewed as written contracts; browser, storage, service and user outcomes remain unverified.

| Condition | Supported lesson | Evidence and next verification |
| --- | --- | --- |
| Queued durable draft writes | Store-generation checks did not explicitly retire an individually discarded draft. The corrected proposal gates every writer on that draft's active identity. Equivalent mechanisms may suit other projects. | IR01; exercise late writers after Discard/Finish and failed retirement against an implementation |
| Multiple observations of one remote action | Action/payload identity does not establish freshness. Preserve confirmed history; authoritative ordering needs a service contract. | IR02/IR03; exercise late and unordered contradictory observations with the actual service |
| Remotely persisted Reject | Reject needs its own pending/unknown/confirmed lifecycle and conflict rules; a lost reply does not prove non-recording. A local dismissal does not inherit these semantics. | IR04; exercise lost acknowledgement, conflicting Confirm and re-entry |
| Overlapping language-pack requests | Only eligible current requests may commit or announce. Old success may cache without replacing the chosen UI. Equivalent cancellation/serialization can be appropriate. | IR06; exercise rapid switches and out-of-order success/failure |
| Inherited focus styling | “Retain the theme indicator” omitted values needed by a self-contained handoff. Embed exact chosen values or stable project-owned token references. | IR07; inspect actual focus visibility, clipping, adjacent surfaces and forced colors |

Evidence owner: Atlas's preserved skill-evaluation trial records and supported findings. No effectiveness rate, production guarantee or user preference follows from these examples. Underlying adapted methods retain the existing creator/license mappings in the skill-adaptation ledger; Atlas's original material has no selected publishing license yet.
